### 배운 것

- **에이전트 보고만으로는 부족하다.** 두 에이전트 모두 「PASS · 디자인 차이 없음」으로 보고했지만, 디자인 캡처 비교(1au 배치)와 독립 QA(1av 높음 2건)에서 결함이 나왔다. 통합 때 캡처 비교와 QA는 빼지 않는다.
- **소유 디렉터리 규칙은 지켜졌다.** 두 작업 모두 소유 밖 변경 0, 병합 충돌 0. 공통 파일(ContentView 개발 메뉴)은 오케스트레이터가 통합 때만 고쳤다.
- **시뮬레이터 충돌.** 다른 세션의 `verify.sh` 기본값(`iPhone 17`)과 겹쳐 테스트 번들 오류가 났다 → 오케스트레이터는 `iPhone 17 Pro Max`로(parallel.md 갱신).
- **이 세션에서 새로 만든 에이전트 정의는 이름으로 부를 수 없다**(세션 시작 때만 읽음). 범용 에이전트에 같은 모델 · worktree 격리를 주고 `.claude/agents/ui-implementer.md`를 읽게 해서 대신했다. 새 세션에서는 이름으로 부를 수 있다.
- **병렬 수는 2 유지.** QA에서 높음 등급이 나왔으므로 3으로 늘리지 않는다.
