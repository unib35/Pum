# MVP — 사장님 혼자 쓰는 월급 계산(iOS)

결정: DEC-028(범위) · DEC-029(기기 안 계산) · DEC-030(SwiftData + iCloud) · DEC-031(계산 범위 · 최소 iOS 18).

## 사용자 흐름

```text
처음 실행 → 시작(2a) → 사업장 만들기(2i)
→ 홈(1aq 단순화)
→ 직원 추가(20a → 20b 기본 정보 → 20c 근로조건 → 20d 계약서 사진, 건너뛰기 가능)
→ 직원 목록(1ac) → 직원 근무(20e: 근로조건대로 자동 채움) → 하루 고치기(20f)
→ 근무 마감(20g) → 월급 계산 · 계산 근거(1u) → 명세서(1m) → PDF로 보내기(20h)
→ 사업장 설정(4c 일부: 급여일 · 5인 이상 여부 · 공제 방식)
```

## 넣는 것 / 빼는 것

| 넣는 것 | 빼는 것 |
|---|---|
| 로그인 없이 시작, 사업장 1곳(여러 곳은 다음) | 휴대폰 인증 · 로그인 · 탈퇴 |
| 직원 등록 · 근로조건(시급 · 월급, 요일 · 시간 · 휴게) | 직원 앱 · 초대 · 알림톡 · 웹 명세서 |
| 월 근무: 예정대로 자동 + 날짜별 고치기(결근 · 시간 변경 · 추가 근무) | 출퇴근 QR · 위치 · 관리자 확인 |
| 근무 마감 → 월급 계산 · 계산 근거 | 스케줄 · 대타 · 공지 · 문서함 |
| 명세서(법정 기재 항목) PDF 공유 | 사업장 인증 · 관리자 · 대표 변경 |
| 기기 저장 + iCloud 백업 | 서버 · 송금 · 지급 기록 |

## 계산 범위(DEC-031)

- 기본급: 시급 × 인정 시간, 또는 월급
- 주휴수당: 주 소정근로 15시간 이상(1주 개근 기준)
- 5인 이상 사업장: 연장(1일 8 · 주 40 초과) · 야간(22–06) · 휴일 50% 가산
- 공제: 사업소득 3.3% 또는 없음
- 금액은 정수 원. 규칙 · 노무 검토 필요 가정: [payroll-rules.md](payroll-rules.md)(코드 `Pum/Pum/Domain/Payroll/`)
- 다음 버전: 4대보험 · 근로소득세 · 퇴직금 · 연차수당
- **출시 전 노무사 확인 권장**(개발 명세서 부록 B 보류 항목)

## 구조(아키텍처 문서 그대로)

```text
화면(View) → ViewModel → UseCase → Repository → SwiftData(+ iCloud)
                             └→ 계산 모듈(Domain/Payroll, 순수 함수)
```

| 단계 | 내용 | 확인 |
