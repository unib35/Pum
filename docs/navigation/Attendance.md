# 근태(Attendance) 화면 연결

요약: 28개 화면 중 **27개** 연결(`AttendanceRoute.connected`). 연결하지 못한 1개는 시간 고르기 시트 데모(C13, 버튼 없음). 연결한 화면 안에서도 일부 버튼은 잇지 못했다(아래 표). 순서의 기준은 흐름 지도 J3 · J4 · J7 · J9 · J12 · J14.

뒤로 = `router.back`, 처음으로 = `router.backToRoot`, 완료 이동 = `router.replace(with:)`. `done(Bool)`을 받는 버튼은 프로토타입이라 `done(true)` 후 이동한다.

| 화면 ID · 이름 | 들어오는 길 | 이은 버튼 → 목적지 | 잇지 못한 버튼 (이유) |
|---|---|---|---|
| 1e 출근 기록 | 직원 홈 출근 버튼 (J3) | 뒤로 → back · 위치로 출근 → 10v | 없음 |
| 10v 위치만 간편 출근 | 1e | 출근하기 → 10t로 교체 | 없음 |
| 10t 출근 판정 통과 | 10v | 확인 → 직원 홈 · 근무 중(1av) | 없음 |
| 21m 출근 판정 중 | 판정 시작 | 뒤로 → back | 판정 결과로의 이동 (버튼 아님, 판정 결과가 있어야 함) |
| 10u 출근 판정 거리 초과 | 판정 실패 | 닫기 → back | 없음 |
| 10w 위치 오차가 클 때 | 판정 실패 | 닫기 · QR로 확인 → back | 없음 |
| 10x 관리자 확인 출근 대기 | 출근 확인 요청 후 | 요청 취소 → back | 없음 |
| 6e 위치 권한 안내 | 첫 위치 출근 | 계속 → 10v로 교체 · QR만 쓸게요 → back | 없음 |
| 6r 위치 권한 꺼짐 | 위치 권한 꺼진 출근 | 뒤로 · QR로 출근 → back | 설정 열기 (시스템 설정, 화면 이동 아님) · 직접 요청 (흐름 지도에 다음 화면 없음) |
| 1f 퇴근 완료 | 퇴근 | 닫기 → 처음으로 | 없음 |
| 1ao 조기 퇴근 | 퇴근 버튼 | 계속 근무 → back · 기록 → 1f로 교체 | 없음 |
| 1al 퇴근 미확정 | 홈 알림 | 요청 → 처음으로 | 없음 |
| 1g 근무 캘린더 (직원 근무 탭) | 탭 | 상세 열기 → 1h · 스케줄 → 내 스케줄(1j) | 사업장 칩 (흐름 지도에 다음 화면 없음) · 달 이동 · 날짜 선택 (화면 안 동작) |
| 6p 근무기록 없음 | 1g (기록 없음) | 스케줄 보기 → 내 스케줄(1j) | 위와 같음 |
| 1h 근무 상세 | 1g | 뒤로 → back · 수정 요청 → 1i | 없음 |
| 1i 근무기록 수정 요청 | 1h | 닫기 · 보내기 → back | 시간 고르기 (화면 안 시트) |
| 1ae 근무기록 확인 요청 | 급여 1ad 시트 (J7) | 뒤로 → back · 확인 → 근무 마감(8a) | 수정 요청 · 행 선택 · 더 보기 (흐름 지도에 다음 화면 없음) |
| 1r 확인 필요 근무 | 1t 위쪽 「확인 필요 근무기록 N건」(DEC-019) | 수정 → 1s · 직접 입력 → 1af | 승인 · 확인 · 예정 퇴근 기록 · 반려 (화면 안 처리, 다음 화면 없음) · 필터 (화면 안 동작) |
| 1s 수정 요청 승인 | 1r | 뒤로 · 반려 · 승인 → back · 직접 수정 → 1af | 없음 |
| 1af 근무기록 직접 추가 | 1r · 1s · 19i · 1ah | 닫기 · 저장 → back | 직원 · 날짜 · 시간 고르기 (화면 안 시트) |
| 1ah 근무기록 삭제 시트 | 사장님 근무기록 행 | 시간 수정 → 1af · 결근 처리 · 삭제 · 취소 · 뒤로 → back | 없음 |
| 2g 개인 기록 상세 | 개인 모드 홈 | 뒤로 · 삭제 → back · 저장 → 저장 완료 후 back | 시작 · 끝 시간 고르기 (화면 안 시트) |
| C13 시간 고르기 시트 | 시트 데모 | (연결 없음) | 시트 데모, 버튼 없음 |
| 10f 마감 후 정정 | 급여 (J9) | 뒤로 → back · 재계산 → 정정 재계산(10g) | 원본 기록 열기 (흐름 지도에 다음 화면 없음) |
| 19g 내 연차 | 문서 · 연차 (J14) | 뒤로 → back · 휴무 신청 → 휴무 신청(10i) | 없음 |
| 19h 휴게를 못 썼을 때 | 1s 다음 (J4) | 뒤로 → back · 보내기 → 완료 후 back | 휴게 못 씀 열기 (화면 안 시트) |
| 19i 휴게 못 씀 확인 | 사장님 알림 | 뒤로 → back · 승인 → 완료 후 back · 다른 시간 → 1af | 없음 |
| 20l 지난 근무기록 | 직원 상세 (J12) | 뒤로 → back · 앱 기록 열기 → 1g | 월 열기 · 이의 제기 (흐름 지도에 다음 화면 없음) |

다른 기능 쪽에서 이 화면으로 들어오는 연결은 그 기능의 Route에서 한다.
