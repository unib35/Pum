# 요구사항 추적표 (Traceability)

> 요구사항(REQ) ↔ 화면(UI) ↔ 테스트·알림·설계 참조. 출처는 Claude Design 프로젝트 「근무 관리 급여 시스템」(2026-10-11 조회, etag는 [디자인 README](../design/README.md#출처와-버전)).

## 규칙

- **REQ 번호는 이 저장소에서 새로 붙였다.** 디자인·명세 문서에 REQ 체계가 없어서다. 기존 번호(화면 ID, TC-, N, M, C/F, A/Q/I/S, R-)는 그대로 참조한다.
- 요구사항 문장은 출처 문서의 확정 내용을 옮긴 것이다. 새 요구사항을 만들거나 UI를 바꾸지 않았다.
- **확정도**: `확정` = 프로젝트 CLAUDE.md의 「사용자 확정」 또는 설계 문서에 확정으로 적힘 · `미확정` = 노무·법무 검토, 미결정 질문 · `충돌 #n` = [디자인 README 충돌 표](../design/README.md#충돌) 번호 · `향후` = V1 범위 밖으로 적힘.
- 화면 열의 ID는 [screen-index.md](../design/screen-index.md)의 `UI-<플랫폼>-<ID>`와 같다. 지난 안 화면도 이력 추적을 위해 포함했다(디자인 표시는 screen-index 참고).
- 버전은 출처에 적힌 경우만. 출시 로드맵에 화면 ID가 없어 대부분 비어 있다.
