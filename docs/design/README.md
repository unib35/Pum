# 디자인 자료 — 품(Pum) 근무·급여

Claude Design에서 확정한 설계를 구현 기준으로 정리한 문서다. **UI를 다시 설계하지 않는다.** 원문과 이 문서가 다르면 원문(디자인 캔버스)이 맞다.

- 화면별 목적·상태·이동·인터랙션·데이터·권한 → [screen-index.md](screen-index.md) (265장)
- 요구사항 ↔ 화면 ↔ 테스트·알림 추적 → [../requirements/traceability.md](../requirements/traceability.md)
- 충돌에 대한 사용자 결정 → [decisions.md](decisions.md) (DEC-001–DEC-007, 원문보다 우선)

- iOS 목차는 탭 상태만 가지고 한 번에 화면 파일 하나만 불러온다. 주소 `#<화면 ID>`로 열면 `ios-map.json`으로 탭을 찾아 그 화면으로 이동한다.

- 플랫폼 범위(CLAUDE.md): V1 = iOS 전체 + Android 직원·개인 모드 + Web(PC·태블릿). Android 사장님 모드는 V2. 직원용 모바일 웹은 만들지 않는다.

## 예시 데이터 불일치 (낮은 우선순위)

화면에 들어간 예시 값이 화면마다 다르다. 구현 요구사항은 아니지만 QA 시나리오를 만들 때 헷갈릴 수 있어 기록한다.

- 사업장 「종민김밥 본점」 주소가 화면마다 다름(서울 마포구 양화로 12 / 대구 수성구 들안로 12 / 부산 김해시 장유로 12)
- 계정 주인 · 대표가 화면마다 다름(이종민 / 박민수), 같은 번호 010-4821-7733
- 직원 수 4명 / 5명, 금액(7c 1,062,000 → 7d 1,188,000 등), 날짜 · 요일(6l "10월 10일 금" — 2026-10-10은 토요일), 앱 버전(1.0.0 / 1.4.2 / 1.4.3)
- 초대 코드 15b `8F3 K2Q` vs 15e 입력 `8F3K2P`(오류 예시일 수 있음)

전체 목록(200건)은 추출 원본에 있고 이 문서에는 구현에 영향이 있는 것만 옮겼다.

## 이 문서를 갱신하는 법

1. `claude_design` MCP `list_files`로 etag를 받아 위 표와 비교한다.
2. etag가 바뀐 파일만 다시 읽고 screen-index · traceability의 해당 행을 고친다.
3. 디자인에서 확정 · 지난 안 표시가 바뀌면 screen-index의 "디자인 표시" 열과 traceability의 화면 열을 함께 고친다.
